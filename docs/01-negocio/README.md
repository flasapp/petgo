# 01 · Negocio

Aquí se define **qué servicio se ofrece, a quién y bajo qué condiciones comerciales**. Las reglas de seguridad del viaje pertenecen a [Operaciones](../02-operaciones/README.md), aunque las políticas comerciales deben respetarlas.

## Documentos iniciales

- [Modelo y servicios](modelo-y-servicios.md): clientes, oferta, cobertura, horarios y límites.
- [Políticas comerciales](politicas-comerciales.md): reservas, admisión, esperas, cancelaciones, responsabilidades y cobro desde el punto de vista del cliente.
- [Decisiones de negocio](decisiones.md): registro de acuerdos de esta área.

## Temas a desarrollar

- Segmentos de clientes y propuesta de valor.
- Servicios por tipo de viaje y zonas de cobertura.
- Reglas para mascotas, tutores y acompañantes.
- Ventanas horarias, anticipación mínima, puntualidad y seguimiento.
- Condiciones de reserva, cancelación, ausencia del cliente y reembolso.
- Atención al cliente, quejas, garantías y límites de responsabilidad revisados con asesoría competente.
- Acuerdos con empresas, veterinarias, peluquerías y refugios.

Cuando las políticas crezcan, se pueden separar en archivos dentro de `politicas/`, conservando este índice.
