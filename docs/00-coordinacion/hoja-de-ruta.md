# Hoja de ruta inicial

El orden responde a las dependencias entre decisiones. Las fechas se acordarán cuando se conozca la disponibilidad y el objetivo de lanzamiento.

| Etapa | Resultado verificable | Estado |
| --- | --- | --- |
| 1. Definir alcance | Ciudad, zonas, clientes, servicios, horarios y condiciones de admisión. | En curso: base y alcance general definidos |
| 2. Validar transporte | Configuración de la Strada, equipamiento, protocolo de bienestar y respuesta a incidentes. | En curso: distribución, cupo e instalación probada declarados; faltan medidas y protocolo documentado |
| 3. Verificar requisitos | Actividad, seguros, documentos, impuestos y condiciones locales confirmadas con fuentes competentes. | Pendiente |
| 4. Calcular economía | Costos reales, tarifa mínima, fórmula de cotización y escenarios de rentabilidad. | Pendiente |
| 5. Crear marca | Nombre, posicionamiento, identidad visual y mensajes coherentes con la oferta. | Pendiente |
| 6. Preparar venta | Reservas, cobros, canales, alianzas y material de lanzamiento. | Pendiente |
| 7. Crear web | Contenido, experiencia, implementación, pruebas y publicación. | Pendiente |
| 8. Medir y ajustar | Consultas, reservas, costos, satisfacción, incidentes y mejoras. | Pendiente |

Una etapa puede avanzar en paralelo con otra si no depende de una decisión todavía abierta. Antes de aceptar viajes deben estar resueltos transporte seguro, condiciones del servicio y requisitos aplicables.
