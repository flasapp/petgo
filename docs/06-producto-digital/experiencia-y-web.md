# Experiencia y web

Estado: **Borrador de requisitos; portada bosquejada y alcance final pendiente**.

La [dirección visual verde pastel](../04-marca/direccion-visual-verde-pastel.md) orienta la apariencia de la web. Las pantallas y los mensajes concretos se definirán según el servicio y el proceso de reserva aprobados.

La primera portada se dirige a **tutores particulares**, destaca **Montevideo** y usa **WhatsApp** como acción principal. Ver [bosquejo de inicio](bosquejo-inicio.md).

## Tareas del visitante

1. Comprender qué viajes se ofrecen, dónde, cuándo y con qué condiciones.
2. Conocer cómo se cuidará y transportará a su mascota, según prácticas comprobadas.
3. Consultar disponibilidad y precio o pedir una cotización.
4. Reservar por el canal elegido y saber cuándo la reserva queda confirmada.
5. Encontrar contacto, políticas y respuestas a dudas frecuentes.

## Páginas o secciones candidatas

Inicio, servicios, zonas, cómo funciona, cuidado y confianza, precios o cotización, preguntas frecuentes, contacto/reserva y páginas legales. El mapa final debe responder al proceso real de venta, no a una lista de páginas por costumbre.

## Decisiones de experiencia

- La primera versión abre WhatsApp para consultar un viaje. Falta definir qué información debe enviar el cliente y cómo se confirma la reserva.
- ¿El precio será estimado, fijo o confirmado manualmente?
- ¿Qué datos se piden al principio y cuáles después de confirmar?
- ¿Cómo se muestran límites de cobertura, horarios y condiciones de admisión?
- ¿Qué mensaje recibe el cliente si el viaje no se puede aceptar o falta información?

Para cada flujo se documentarán pantallas, campos, validaciones, estados y texto de confirmación. El diseño debe funcionar primero en móvil y ser usable con teclado y tecnologías de asistencia.
