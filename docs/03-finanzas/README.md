# 03 · Finanzas y precios

Aquí se calculan **costos, tarifas, rentabilidad y reglas de cotización**. La política que recibe el cliente se resume en [Negocio](../01-negocio/politicas-comerciales.md); la implementación del cálculo en la web pertenece a [Tecnología](../07-tecnologia/README.md).

## Documentos iniciales

- [Costos](costos.md): inventario de gastos y unidades de medida.
- [Precios](precios.md): estructura de tarifas y recargos por decidir.
- [Algoritmo de cotización](algoritmo-de-cotizacion.md): variables, flujo y pruebas con ejemplos.
- [Proyecciones y métricas](proyecciones-y-metricas.md): punto de equilibrio y seguimiento.
- [Decisiones financieras](decisiones.md).

## Temas a desarrollar

- Inversión inicial y capital de trabajo.
- Costos fijos, variables y desgaste de la camioneta.
- Retribución deseada por hora de trabajo.
- Tarifa mínima, zonas, kilómetros, tiempo, retorno sin pasajero, espera y extras.
- Comisiones de cobro, impuestos aplicables y margen objetivo.
- Escenarios de demanda, flujo de caja, punto de equilibrio y reserva para imprevistos.
- Registro mensual de viajes, ingresos, gastos y rentabilidad real.

Toda cifra deberá tener moneda, fecha y fuente. Ya se registraron el costo de combustible informado y un mínimo futuro; las tarifas finales siguen pendientes.
