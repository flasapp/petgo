# Incidentes y emergencias

Estado: **Pendiente de desarrollar antes del primer viaje**.

## Escenarios a preparar

| Escenario | Qué debe quedar definido |
| --- | --- |
| Retraso o avería | A quién avisar, transporte alternativo y tratamiento del precio. |
| Escape del animal | Prevención, respuesta inmediata, contactos y registro. |
| Malestar o lesión | Criterio para detenerse, contacto del tutor y atención veterinaria. |
| Accidente vial | Prioridades de seguridad, asistencia, comunicación, seguro y evidencia. |
| Entrega fallida | Espera, contacto, lugar seguro y nueva entrega. |
| Conflicto o reclamo | Registro de hechos, respuesta y revisión de la causa. |

Para cada caso se redactará un procedimiento con responsables, teléfonos, decisiones permitidas y registro mínimo. Confirmar cobertura de seguro y responsabilidades en [Administración y legal](../08-administracion-legal/verificaciones.md).
