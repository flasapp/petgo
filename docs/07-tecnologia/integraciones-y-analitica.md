# Integraciones y analítica

Estado: **Por priorizar**.

## Integraciones candidatas

- Mapas: distancia, tiempo estimado y zonas de cobertura.
- Mensajería: consultas, confirmaciones y avisos de viaje.
- Calendario: disponibilidad y prevención de reservas superpuestas.
- Pagos: estado de transacción y conciliación.
- Correo: mensajes de confirmación y soporte.

Para cada integración se anotarán proveedor, costo, datos compartidos, límites, funcionamiento ante una caída y alternativa manual.

## Eventos de medición posibles

Visita a página de servicio, clic de contacto, solicitud de cotización, cotización emitida, reserva confirmada y pago completado. El seguimiento debe corresponder a los objetivos de [Marketing](../05-marketing/metricas.md) y respetar los requisitos de privacidad aplicables.
