# Datos y seguridad

Estado: **Diseño pendiente**.

## Datos mínimos por evaluar

Contacto del tutor, origen y destino, horario, información necesaria sobre la mascota, persona autorizada para entrega y estado del pago. Para cada dato, definir finalidad, quién accede, cuánto tiempo se conserva y cómo se elimina o corrige.

## Controles a definir

- Acceso a reservas y pagos con permisos adecuados y autenticación.
- Copias de seguridad y prueba de recuperación si se usa una base de datos.
- Protección de formularios, comunicaciones y archivos compartidos.
- Gestión de credenciales fuera del repositorio.
- Procedimiento de incidente de datos y revisión de proveedores.

Los textos legales y obligaciones aplicables se verificarán en [Administración y legal](../08-administracion-legal/verificaciones.md).
