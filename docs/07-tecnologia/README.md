# 07 · Tecnología

Aquí se documenta **cómo se construyen y mantienen los sistemas** que apoyan el servicio. Los requisitos de la experiencia se toman de [Producto digital](../06-producto-digital/README.md); las reglas comerciales se toman de [Negocio](../01-negocio/README.md) y [Finanzas](../03-finanzas/README.md).

## Documentos iniciales

- [Arquitectura y despliegue](arquitectura-y-despliegue.md): soluciones candidatas, alojamiento y mantenimiento.
- [Reservas y pagos](reservas-y-pagos.md): estados, integraciones y conciliación técnica.
- [Datos y seguridad](datos-y-seguridad.md): datos mínimos, accesos, retención y copias.
- [Integraciones y analítica](integraciones-y-analitica.md): mapas, mensajería y medición.
- [Decisiones técnicas](decisiones.md).

## Temas a desarrollar

- Dominio, alojamiento, correo, certificados y despliegue.
- Formulario, agenda, disponibilidad, cotización y administración de reservas.
- Proveedor de pagos, estados de transacción, comprobantes y conciliación.
- Integraciones con mapas, WhatsApp, correo y otras herramientas.
- Base de datos, privacidad, permisos, seguridad y respaldo.
- Analítica de la web, rendimiento, accesibilidad técnica y monitoreo.
- Manual de operación y recuperación ante fallos.

La primera versión puede ser manual si cumple la experiencia acordada; se decidirá después de definir el proceso de reserva.
