# Concepto de logo rechazado · 2026-11-14

Esta carpeta conserva el primer concepto de PetGo solo como historial. El emprendedor lo rechazó porque su símbolo no comunicaba traslado ni mascotas y pidió un logo PNG con fondo transparente.

La [propuesta vigente](../../logo/README.md) muestra una camioneta con un perro y un gato. Ningún archivo de esta carpeta debe usarse en la web, redes, impresos o vehículo.

El antiguo generador `build-brand-logo.mjs` queda archivado aquí y no forma parte del flujo activo.
